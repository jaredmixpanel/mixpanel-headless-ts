# Changelog

Release notes are kept per package and written by
[Changesets](https://github.com/changesets/changesets) when a release is cut
(`.changeset/README.md`, `CONTRIBUTING.md` "Releasing"). The three packages
share one version and release together:

- [`@mixpanel-headless/core`](packages/core/CHANGELOG.md)
- [`@mixpanel-headless/node`](packages/node/CHANGELOG.md)
- [`@mixpanel-headless/browser`](packages/browser/CHANGELOG.md)

Changes that touch no published package (the conformance rig, the differential
oracle, scripts, CI) have no changelog entry; the git history is their record.
